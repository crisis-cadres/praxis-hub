# OPSEC and Communication Resilience

- When the social contract begins to fray, maintain operational security for group resources and plans.
- Use encrypted messaging, code words, and proper password hygiene for shared digital assets.
- Establish redundant communication networks: radio, runners, and organized observation protocols.
- Train members in cybersecurity, encrypted communication tools, mesh networks, and radio operation.
- Seemingly simple actions, such as securely managing passwords for common accounts, are part of Security's mandate.
