# Horticulture

- A community garden is a low-risk, high-visibility first project that feeds members and demonstrates the [Cadre model](../cadres/what-is-a-cadre.md) to the neighborhood.
- Organize a Horticulture sub-committee under [Production](../production/index.md) so growing has a clear home and accountable leadership.
- Start with potatoes and other calorie-dense staples: resilient, difficult to mess up, and a reliable baseline of calories.
- If vegetables come from distant suppliers, expand gardens or invest in greenhouses to shrink supply chain reliance.
- Pair staples with perennials and medicinal plants so the garden keeps producing and [surplus](../culture/surplus-recruitment.md) becomes a tool for outreach.
- Multiple seasons are required to perfect growing methods in your context, so start now and treat each cycle as an [after-action review](../appendices/meeting-templates.md).
- A garden is a place to build trust through shared work, where neighbors see resilience happening and want to join.
