# Praxis Hub

A living wiki for community resilience. The wiki is built with MkDocs from
markdown generated by `wiki/generate.py` and deployed to GitHub Pages via
GitHub Actions.

## Pages

- Home — full summary of the Praxis Hub framework
- The Core Philosophy
- The Four Pillars of Operations
- Organizational Strategy and Growth
- Tactics and Governance

## How it works

1. The wiki's content lives as one committed markdown page per section in
   `wiki/docs/` — the homepage (`index.md`) is assembled from those pages. Every
   page footer has an "Edit this page" link that opens the page's markdown in
   your browser on GitHub.
2. `wiki/generate.py` normalizes each page (appends the discussion footer) and
   regenerates the homepage.
3. The GitHub Actions workflow runs the generator, builds the site with
   `mkdocs build`, and deploys it to the `gh-pages` branch.

## Discuss

Every page footer links to the GitHub Issues tracker for the relevant page.

## Contribute

To propose a change, open an issue or edit a page's markdown in `wiki/docs/`
and open a pull request.
